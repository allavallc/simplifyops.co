# Reference

**Neutral definitions, concepts, options, and schema summaries** — factual "what is X" lookups with no
opinion and no steps.

**Put here:** definitions, glossaries, lists of options, structure summaries.
**Not here:** how to do something (→ `processes`) or a rule/opinion (→ `principles`).

_Example:_ "MRR (monthly recurring revenue): definition, how we calculate it, what's included/excluded."
