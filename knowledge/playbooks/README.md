# Playbooks

**Complete scenario guidance** — how to handle a whole situation end to end, weaving together
principles, processes, and judgment.

**Put here:** "when THIS happens, here's how to handle the entire thing."
**Not here:** a single mechanical task (→ `processes`), or a standalone rule (→ `principles`).

_Example:_ "Handling an unhappy client: assess the real issue → acknowledge → present options →
agree next step → follow up in writing."
