# Processes

**Repeatable, mechanical steps** — an ordered how-to for one task with a clear start and end. Given
the same inputs, anyone following it gets the same result.

**Put here:** deterministic "how do I do X" step lists.
**Not here:** the reasoning behind the steps (→ `principles`), or judgment-heavy, multi-part situations
(→ `playbooks`).

_Example:_ "Month-end invoicing: 1) generate invoice, 2) review, 3) send, 4) finalize & stamp #."
