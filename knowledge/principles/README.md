# Principles

**Durable rules and decision truths** — the stable "always / never / prefer" statements (and the
reasoning behind them) that guide many decisions.

**Put here:** things that stay true across situations and shape judgment.
**Not here:** step-by-step how-to (→ `processes`), or handling a whole situation (→ `playbooks`).

_Example:_ "Never commit to a delivery date before confirming capacity — an over-promise costs more
trust than a slower honest estimate."
