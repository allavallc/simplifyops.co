# Real-life examples

**Mistakes, lessons, costs, and fixes** — concrete things that actually happened, distilled into the
lesson so we don't repeat them. Learning-oriented and short.

**Put here:** "we did X, it cost Y, the fix is Z."
**Not here:** the full narrative of an engagement (→ `case-studies`) — this is the takeaway, not the story.

_Example:_ "Skipped `finalize_invoice.py` once → the same hours re-billed next month. Fix: always
finalize immediately after generating."
