## Blog Post Format (Jekyll)

**Filename:** `YYYY-MM-DD-title-slug.md`
- Example: `2026-03-30-cash-flow-management.md`
- Use lowercase, hyphens instead of spaces

**Front matter (required at top of file):**
```yaml
---
layout: post
title: "Your Post Title Here"
date: YYYY-MM-DD
description: "One sentence summary for SEO (under 160 chars)"
categories: [operations, finance]
---
```

**Then the post content in markdown.**

## Publishing
After Human approves a post:
1. Save post to `./_posts/` with correct filename format
2. Git add, commit with message: "Publish: [post title]"
3. Git push to origin main
4. Update request log status to "Published"
